Rasch Models for examining pedestrian barriers for walking over time
================

## Content

This page was created for providing the code and dataset in order to
reproduce the results of the paper cited below, aligned with the
transparency principles.

> Valença, G., Boani, B., Humberto, M., & Moura, F. *Examining
> perceptions of walkability among pedestrians at different times of the
> day*. Paper currently submitted for revision (2026).

- [Code](RaschModel_Final.R) for performing Rasch Models

- [Treated dataset from the survey](data.xlsx)
